# 星際命題室｜A／B 卷洗牌工具

設計 by 楊依依老師｜Emily AI Studio

單一 HTML 離線工具，可建立 A／B 卷、隨機重排題目與選項、自動更新答案，並列印試卷或答案表。題目只在使用者的瀏覽器中處理，不會上傳。

## 使用方式

- 開啟 `index.html` 即可使用，也可透過 GitHub Pages 線上開啟。
- 可載入內建範例或貼上題目，再選擇 A 卷、B 卷或答案表預覽。
- 點選「複製兩卷答案」會複製答案；列印按鈕可列印所選試卷。
